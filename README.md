# Solavisetech-women-in-data-cohort-3

Solavisetech women in data program, abbreviated as SWID is a program made to empower women in the field of data in computer science by Solavise technology institute (Solavisetech) for women ONLY worldwide over 3 months. It is a weekend program. Solavisetech women in data (SWID) is highly practical. It was founded by Dr Samba Otavise. This program also prepares women for professional adaptation. They teach professional tools like GitHub, discord, emails etc. Also they train on soft skills like communication, teamwork, networking etc. They also train on how to have a professional presence on social media like LinkedIn.

## My achievements by the end of the program

 ### Connections and networks:
 I wish to have connections and networks with people in my professional field.

 ### Soft skills: 
 I wish to develop my communication skills. I am an introvert. I want to stop using introvertedness as a label. I want to grab opportunities when they come.

 ### Tech skills: 
 I want to master data science, machine learning, big data, and cloud computing for my professional world.

 ###Social media presence and professional skills:
 I want to build a professional presence on LinkedIn. I want to know how to use professional tools like GitHub, Discord, and email professionally.

 ###My personal ambitions: 
 I want to help others overcome introversion to foster collective growth.
